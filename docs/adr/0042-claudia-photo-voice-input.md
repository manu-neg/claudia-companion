# ADR 0042: Claudia understands the owner's photos and voice notes

**TL;DR:** The owner's private chat may send voice notes and photos to Claudia (C61 intake, C62 transcription). Photo and voice input are **on by default** (owner 2026-11-09); voice output stays off (`claudia_voice_input_enabled`, `claudia_photo_input_enabled`, each needs `claudia_enabled`; an explicit `false` turns one off; without the pinned whisper install the host turns voice input off with one alert). Voice is decoded and transcribed locally (whisper.cpp v1.9.5, `ggml-base`, hash-pinned) inside a no-network sandbox; the transcript then takes the same screen as typed text. Photo turns get the **read-only** tool set by default; whether they should get the full set is still the owner's open choice. Unit F-CL4 (A intake, B host, C deploy); owner decision 2026-11-09.

## Context
- Claudia only read texts. The owner wanted to send a photo or talk to her.
- Media is attacker-shaped bytes arriving from outside, parsed by libraries, and (photos) read by a model that obeys text it finds.
- No cloud transcription: audio must not leave the server (C35 egress allow-list stays unchanged).

## Decision
- **Intake (C61, unit A):** `voice` and `photo` messages count only from the owner's private chat (same check as texts, before anything else). Caps come first from Telegram's metadata (voice ≤ 120 s, ≤ 2 MiB, `audio/ogg`; photo ≤ 10 MiB, each side ≤ 4096 px), then again **by content** in the admin: Ogg with an `OpusHead` first stream and a re-checked duration; JPEG structure and size with every APPn/COM segment stripped byte-wise (no image library). Photos sent as a document, albums (media groups) and anything else are refused. The file is fetched on the same Telegram API host, byte-capped while streaming, and handed to the admin as a **JSON body with base64 media** (one route, the existing request-size limit stays honest); the host fetches it by message id.
- **Transcription (C62, unit B):** the host decodes the Ogg/Opus to 16 kHz mono WAV with `soundfile` and runs `whisper-cli` on that WAV **inside one `systemd-run` sandbox** (`PrivateNetwork`, `DynamicUser`, `ProtectSystem=strict`, read-only model, `MemoryMax`, `RuntimeMaxSec`, no env, no tokens). Binary and model are hash-pinned (`deploy/claudia/whisper.sha256`); a mismatch turns voice input off with one `failed` alert. The transcript is marked "(transcribed voice note)" and goes through the same parser and Haiku screen as typed text (C48).
- **Photo turns:** the caption is screened like text; the JPEG is copied 0600 into the run's work dir, deleted when the run ends, and named in the prompt inside the untrusted-data framing. Tool set = `claudia_photo_turn_tools`: **`read_only` by default**; `full` is one config value. The owner has not decided; the PR says so.
- **Deploy:** `install.sh --whisper` (opt-in, needs `--claudia`) downloads the pinned source tarball and model, checks both hashes **before** extracting, builds CPU-only with PyPI `cmake`/`ninja` run through `uv` (no apt, no system package), installs to `/opt/claudia-whisper` (root, 0755/0644) and records the binary hash. It never edits the live config; `check.sh` re-verifies and warns.
- **Unit A choices:** an off switch drops the update plus one fixed owner notice (`MEDIA_OFF` / `MEDIA_REFUSED`) at most once per hour; media files are swept after 23 h (message purge is 24 h) and released early by the host; the Claudia DB moves to **v2** by additive `owner_messages` columns (`kind`, `media_id`, `media_bytes`), so the admin must restart before purge and host.
- **Dependency check (2026-11-09):** no open advisory on our path. whisper.cpp audio CVE-2025-14569 and CVE-2026-17512 are not confirmed fixed, so only a host-generated canonical WAV ever reaches it, and only in the sandbox. libsndfile 1.2.2 has open CVEs in its WAV/AIFF/MAT4/MPEG parsers, so Ogg/Opus is content-checked first and the decode runs in the same sandbox. No ffmpeg.

## Consequences
- A bug in whisper.cpp or libsndfile costs a throw-away sandbox with no network, files or secrets, not the host.
- Photo turns with `full` tools can be steered by text inside an image (prompt injection); C59/C46 approvals remain the backstop. Hence read-only by default (security.md Known limitations). Transcripts can be wrong; the marker tells her so.
- A source build adds a compile step to deploys (a few minutes, once per pin change) and an extra hash to maintain; pins change only by editing `whisper.sha256` and the install.sh URLs together.
- Rejected: cloud transcription (audio leaves the server), ffmpeg (large parser surface), accepting media from any chat or as documents.
